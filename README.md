# AI 图片工作台

**在一个浏览器页面里完成 AI 图片生成、参考图编辑与批量任务管理。**

支持 OpenAI、Gemini 和 Vertex 接口，将连接配置、多图参考、任务队列、图片预览与下载整合在同一个中文界面中。采用单文件 HTML，无需安装前端依赖或执行构建。

AI Image Workbench · 基于 Vertex Ultra V3.1 版本整理

## 功能特点

| 功能 | 说明 |
| --- | --- |
| 多服务商切换 | 分别保存 OpenAI、Gemini、Vertex 的连接设置，支持自定义 Base URL 与模型 ID |
| 图片生成与编辑 | 输入提示词生成图片，或上传参考图进行编辑；OpenAI Images 模式根据是否有参考图选择生成或编辑接口 |
| 多图参考 | 支持选择、拖入和粘贴图片，可拖动调整参考图顺序 |
| 批量任务 | 设置任务数量和最大并发，支持暂停队列、取消、停止和重试 |
| 输出参数 | 提供尺寸、宽高比及部分接口的质量、格式等选项，实际支持范围取决于所选模型与服务商 |
| 上传优化 | 可选参考图压缩、最长边限制，以及 Gemini / Vertex 的参考图解析精度 |
| Vertex 凭据池 | 支持按 `KEY\|PROJECT_ID` 每行一组配置，按任务与重试轮换凭据 |
| 本地历史 | 使用 localStorage 保存设置，使用 IndexedDB 保存任务历史、缩略图与图片数据 |
| 图片查看 | 支持大图浏览、缩放、切换、复制和单张下载 |
| 批量导出 | 支持任务 ZIP、全部结果 ZIP；兼容的浏览器还可授权文件夹并自动保存图片 |
| 故障排查 | 提供任务状态、错误提示与脱敏 RAW 请求及响应信息；对 HTTP 429 进行退避重试 |

## 快速开始

### 方式一：直接打开

下载本仓库后，用较新的 Chrome 或 Edge 打开 `index.html`，即可查看和配置工作台。页面通过 CDN 加载 Tailwind CSS 和 JSZip，需要能访问相应网络资源。

如果浏览器限制本地文件的存储、跨域请求或其他能力，使用下面的本地服务方式。

### 方式二：通过本地服务打开

在项目文件夹中打开终端，运行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

浏览器访问 [本地工作台](http://127.0.0.1:8000)。结束时，在终端按 `Ctrl+C` 停止服务。

此命令需要已安装 Python 3，只负责提供静态文件；图片 API 请求仍由浏览器直接发送。它不会代理接口，也不会绕过服务商的跨域限制。

## 使用流程

1. 在左侧选择 OpenAI、Gemini 或 Vertex。
2. 填写对应服务商的 API Key，核对 Base URL、API 版本和模型 ID。使用自定义网关时，填写网关要求的配置。
3. 输入提示词；需要参考图编辑时，选择、拖入或粘贴图片，并按需要调整顺序。
4. 设置输出参数、生成任务数和最大并发。首次使用建议先设为 1 个任务、1 个并发，确认接口可用后再增加。
5. 点击「开始生成」，在结果区查看任务进度与图片。
6. 下载单张图片或导出 ZIP；需要自动保存时，先选择文件夹并授予浏览器写入权限。

## 接口模式

下表说明当前项目构造的请求形式。模型 ID、接口可用性、权限、参数与价格请以你使用的服务商为准；页面内置预设不代表账号一定有访问权限。

| 服务商 / 模式 | 项目使用的接口路径 | 说明 |
| --- | --- | --- |
| OpenAI Images | `/images/generations`、`/images/edits` | 无参考图时生成，有参考图时编辑 |
| OpenAI Chat | `/chat/completions` | 适用于支持图片输入与图片输出的兼容通道，不能用于保证任意聊天模型出图 |
| Gemini | `/models/{model}:generateContent` | 使用所配置版本的 GenerateContent 接口 |
| Vertex 项目模式 | `/projects/{project}/locations/global/publishers/google/models/{model}:streamGenerateContent` | 凭据池条目包含 Project ID 时使用 |
| Vertex Express | `/publishers/google/models/{model}:generateContent` | 默认 Key 未配置 Project ID 时使用 |

Base URL 填写服务根地址，API 版本在单独的输入框中填写，避免重复拼接版本路径。使用自定义网关时，仍需检查其路径规则和跨域策略。

Vertex 凭据池格式示例，以下均为占位符：

```text
YOUR_VERTEX_KEY_1|YOUR_PROJECT_ID_1
YOUR_VERTEX_KEY_2|YOUR_PROJECT_ID_2
```

Gemini / Vertex 的单任务图片数量在当前项目中固定为 1；需要多张图片时请增加「生成任务数」。1K / 2K / 4K 等尺寸是参数快捷选项，最终是否受支持由模型和接口决定。Chat 模式的额外图片参数及流式预览属于兼容性选项，部分网关可能不支持。

## 数据保存与密钥

- API Key、Vertex 凭据池和连接参数会以明文保存在当前浏览器的 localStorage 中，并用于浏览器直接请求所配置的服务商或网关。
- 上传的参考图与提示词会发送到你配置的接口；本项目没有额外提供图片 API 后端。
- 图片和任务历史保存在当前浏览器的 IndexedDB 中，当前实现最多持久化最近 120 个任务。清理浏览器站点数据可能同时清除设置和历史，请及时下载需要保留的结果。
- 浏览器中输入的密钥与历史不会自动写回 `index.html`。分享 HTML 文件或克隆仓库不会同步这些浏览器数据。
- RAW 信息包含脱敏处理；反馈问题或分享日志前，仍请检查其中是否含有自己的提示词、图片信息或其他个人数据。
- 建议在自己的设备上使用。面向多用户部署时，应增加后端代理与鉴权，避免将长期密钥放在前端。

## 浏览器与网络要求

- 建议使用较新的桌面版 Chrome 或 Edge。自动保存到文件夹依赖 File System Access API、浏览器授权及安全上下文，通常需要 HTTPS 或 localhost。
- 不支持文件夹写入的浏览器仍可使用普通下载和 ZIP 导出。剪贴板及复制图片能力也可能受浏览器权限与安全上下文限制。
- 页面通过 CDN 加载 [Tailwind CSS](https://cdn.tailwindcss.com) 和 [JSZip 3.10.1](https://cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js)，当前版本并非完全离线应用。
- 图片生成需要自行准备可用的接口凭据，可能产生服务商费用。接口必须允许当前页面来源发起跨域请求。

## 常见问题

**页面能打开，但生成请求失败？**

先检查 API Key、模型权限、额度、Base URL 和 API 版本，再查看任务提示与脱敏 RAW。出现浏览器跨域错误时，需要由接口服务商或你控制的后端配置允许的来源；静态页面本身无法解除服务端跨域限制。

**Chat 模式提示 `unknown parameter`？**

尝试关闭「Chat 模式附加图片参数」，并核对所用网关支持的模型、输入格式与返回格式。

**遇到 HTTP 429？**

工作台会退避重试；如果持续限流，请降低并发、检查服务商额度与容量，必要时稍后重试。

**更换浏览器、电脑或访问地址后，看不到原来的配置和历史？**

数据保存在各自的浏览器与站点来源下，不会自动跨设备、跨浏览器或跨地址同步。
